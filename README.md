# demo-landing-live

Repositorio de staging para la demo web. Cada push a `main` despliega automáticamente la landing estática en Cloudflare Pages.

URL de staging: <https://demo.raul.re>

URL alternativa de Cloudflare Pages: <https://demo-landing-live.pages.dev>

La página actual es únicamente un placeholder para validar la tubería de despliegue.
